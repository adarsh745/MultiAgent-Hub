# WorkPilot AI - Frontend

This directory contains the user interface components for WorkPilot AI.

## Planned Contents

* **Dashboard UI**: Real-time monitoring of agent activities, execution pipelines, and workflow metrics.
* **Agent Management**: Interfaces for configuring, monitoring, and deploying autonomous agents.
* **Human-in-the-Loop Views**: Interactive tools for human review, approval workflows, and prompt interactions.
* **System Settings**: Role-based access control, integration settings, and audit logs.
