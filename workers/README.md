# WorkPilot AI - Workers

This directory contains background task workers and queue handlers for asynchronous job processing.

## Planned Contents

* **Queue Consumers**: Handlers for consuming asynchronous tasks from Redis, Celery, or RabbitMQ queues.
* **Scheduled Tasks**: Cron jobs, periodic agent heartbeats, and maintenance tasks.
* **Long-running Jobs**: Asynchronous execution runners for complex agent workflows, document ingestion, and batch data processing.
