# WorkPilot AI - MCP Servers

This directory contains Model Context Protocol (MCP) server implementations used across WorkPilot AI.

## Planned Contents

* **Custom MCP Servers**: Standardized protocol adapters connecting AI agents to enterprise APIs, legacy applications, and custom databases.
* **Integrations**: Pre-configured connectors for third-party tools (e.g., Slack, GitHub, Jira, PostgreSQL, filesystem).
* **Protocol Specs**: Shared schemas, transport configuration, and tool exposure primitives.
